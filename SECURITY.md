# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

Only the latest commit on the `main` branch is supported with security updates.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Instead, please report vulnerabilities through GitHub's private reporting:

1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Fill in the details and submit

You can also use [GitHub Security Advisories](https://github.com/bronfmanmarina15620-crypto/stock-forecasting-system/security/advisories/new) to report privately.

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

This project is a reference implementation for educational purposes. It does not handle real financial transactions. However, we still take the following seriously:

- Secrets or credentials accidentally committed
- Dependency vulnerabilities
- Code injection or path traversal in pipeline scripts
