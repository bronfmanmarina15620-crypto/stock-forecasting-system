# Troubleshooting

## Symptom: "Context remaining < 25%" / Auto-compact triggers

* Action: Start a new chat after completing a milestone.
* Action: Use CONTEXT_HANDOFF.md as the first message in the new chat.

## Symptom: Assistant proposes changing strategy / adding indicators

* Action: Point to SYSTEM_INVARIANTS.md (Single Strategy) and stop the change.

## Symptom: Conflicting pipeline order in suggestions

* Action: Point to ARCHITECTURE_SNAPSHOT.md and AGENT_CONTRACTS.md.
